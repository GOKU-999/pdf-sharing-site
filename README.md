# PDF Sharing Website

A free platform to upload, share, and view PDF files online.

## Features
- 📁 Upload PDF files (max 10MB)
- 🔗 Generate shareable links
- 👁️ View PDFs in browser
- 📥 Download option
- 🎨 Responsive design

## Technologies Used
- HTML5, CSS3, JavaScript
- Firebase (Storage)
- PDF.js (PDF rendering)
